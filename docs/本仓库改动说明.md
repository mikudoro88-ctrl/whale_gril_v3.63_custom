# 本仓库改动说明（相对上游 Banan1cee/whale_gril v3.63）

本文件记录本 fork 相对原版做的改动，方便追溯与回滚。原版 LICENSE（MIT）保留，版权归原作者，本分支同样以 MIT 发布。

## 一、识图（认图）链路
- `src/imageSearch.js`：新增 `identify()`（多来源交叉核对）、`traceMoe()`、`sauceNao()`、`anilistMedia()`、`featureWords()/corroborates()`、`safeComplete()`、`enrich()` 的以图搜图/特征搜索降级。
- 证据分级：`verified`（图搜+网页核对）/`reverse`（仅图搜命中）/`sauce`/`guess`（只有网页线索，必须说"可能"）/`unverified`/`none`。
- 以图搜图阈值 0.9（低于 0.95 时措辞降级为"疑似"），SauceNAO 需 ≥70%。
- `src/websearch.js`：Bing+搜狗并行、相关度过滤、按命中词数排序；新增 Edge/Chrome 无头浏览器兜底（`browserSearch()`，带 10 分钟缓存与单飞）。
- `src/persona.js`：加了"识图说疑似/查不到时不许报定论""被纠正或给出名字时先搜再答"两条规则。

## 二、看图与联网
- `src/imageSearch.js#enrich()`：模型判断图里有专有名词才搜，纯图/截图跳过。
- `src/vision.js`：`vision.thinking` 开关（off 默认，看图快 5 秒）；`max_tokens` 下限 2048、空正文重试。
- `src/llm.js`：`noThink`/`relaxTokens`/`temperature` 参数；`thinking:{type:'disabled'}` 支持。
- `src/dshBridge.js`（新增）：可选接 DeepSeek Harness 做看图描述与难图复核（`dshBridge.enabled`）。

## 三、微信桥接（examples/wechatauto_bridge.py）
- 收图先问用途：私聊立刻问；群里挂起，等发图人叫别名/@ 再问，下一句 90 秒内合成处理。
- 文档/聊天截图：识别为总结类需求时只转写文字、不联网。
- 群里 @ 支持纯文本模式（`wechat.imageAsk.atUi=false`，避开 UI @ 卡死）；群昵称从 `chat_room.ext_buffer` 解析并 60 秒缓存。
- 表情包：30% 概率回"服务器繁忙，请稍后重试"（`wechat.stickerBusy`）。
- 主动分享：B 站视频下载后以视频消息发出（`share.sendVideo`）。
- 收到别人发来的 B 站链接：自动下载完整视频回发（`wechat.videoLink`），可配上限/画质/冷却/发完删除/是否回退搜索框。
- 群聊批处理（`wechat.batch`）、打字停顿（`wechat.liveness`）、发送失败三级降级。
- 启动时自动拉起主服务（`scripts/ensure-whale.bat`，由 `bridge_loop.bat` 调用）。

## 四、聊天内核
- `src/access.js`（新增）：允许范围白名单 + 逐聊天权限（chat/full/off）。
- `src/archive.js`（新增）：记忆分层（私聊档案/群档案/群友印象），2 秒防抖落盘到 `data/archives.json`。
- `src/mood.js`（新增）：8 种情绪 + 强度/衰减 + 后台归纳，`GET /api/mood`、`POST /api/mood/reset`。
- `src/cost.js`（新增）：按 token 用量与官方价计算每条回复费用，`pricing` 可关。
- `src/selfEdit.js`（新增）：让人设由模型自己改写（带快照与撤销），`POST /api/persona/selfedit`、`/api/persona/undo`。
- `src/bot.js`：活人感（双气泡概率/开场白防复读）、动态温度、记忆档案注入、费用行、白名单闸门、
  `masterAlwaysReply=false` 时主人在群里没 @ 不接话（修"永远回"）。
- `src/persona.js`：Prefix-Cache 三层（固定头 → 人设 → 易变尾），自定义人设放最后（旧代码把它排最前会被通用规则压制）。
- `server.js`：`/api/vision` 两处接入识图链路；`readBody` 上限 8MB；新增 `/api/mood*`、`/api/persona/selfedit|undo`、
  `/api/config` 嵌套 patch。

## 五、网页
- `web/persona.html`：新增"让她自己改人格"卡片。
- `web/debug.html`：新增"新功能开关"卡片（9 组，25 个字段），排版与"全部设置"一致。

## 六、数据与隐私
- `data/`、`config.json`（含 API Key）、`runtime/`、日志一律不入库（见 .gitignore）。
- 首次运行会从 `config.example.json` 生成 `config.json`；`data/` 会自动重建。

## 七、回滚
每个改动在本地 `patches/<主题>/` 里都有改前备份（未入库）。要回滚某个补丁，用它同名的 `.bak-*` 覆盖回去、重启服务即可。
